# ARP Lab with DHCP Server (Cisco Packet Tracer)

A three-switch network with a DHCP server (192.168.1.1) assigning IP addresses to 13 PCs. Used to observe how ARP maps IP addresses to MAC addre

How to run
1. Download the .pkt file from this repository.
2. Open it in Cisco Packet Tracer.
3. Open any PC > Desktop > Command Prompt and run `arp -a` or `ping` another PC to see ARP in action.
